How to use this syllabus audit

Try to say, calculate or sketch each statement without notes. Tick green only if you can demonstrate it; amber if you hesitate or need prompting; red if you cannot yet do it. You can change or untick a rating at any time. Use the Red filter as your revision to-do list, then practise questions from the Bounomics Economics Question Bank.

HL-only items are marked. The fixed progress display always counts the full selected course, not merely the current search results. The grey slice is unassessed statements.
